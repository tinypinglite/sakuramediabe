# Release: 发现页推荐能力更新

发布日期：2026-05-10

适用范围：`v0.2.6` 之后的后端更新

## 变更摘要

本次更新重点补齐发现页的个性化推荐能力，新增“每日推荐”和“推荐时刻”两类只读推荐接口，并配套定时生成任务、数据库迁移、配置项与接口文档。用户侧可以在发现页看到更稳定的影片推荐列表，也可以浏览基于收藏时刻、相似影片和热门影片生成的可播放时间点推荐。

## 新增功能

### 每日推荐

新增 `GET /daily-recommendations`，用于分页读取最近一次成功生成的每日推荐快照。

- 推荐候选来自全库非合集影片，不要求影片已经有本地媒体文件。
- 响应会返回推荐分、推荐原因、分项信号分以及影片卡片信息。
- 如果当天推荐任务尚未生成成功，接口会继续返回上一批推荐，并通过 `is_stale=true` 标记过期快照。
- 如果系统从未生成过推荐快照，接口返回空分页，不会在请求线程中临时计算。

### 推荐时刻

新增 `GET /moment-recommendations`，用于分页读取当前推荐时刻池。

- 推荐内容定位到具体媒体、缩略图和播放时间点，前端可以直接用于“点开即看”的时刻卡片。
- 推荐来源包含 `visual`、`similar_movie`、`popular` 三类策略：收藏时刻视觉相似、相似影片相近时刻、热门影片精选时刻。
- 响应包含时刻缩略图签名 URL、影片卡片、推荐理由、分数、媒体 ID、缩略图 ID 和 `offset_seconds`。
- 同一推荐池内分页稳定；生成失败时保留旧推荐池，生成成功但无候选时清空旧池。

## 推荐生成任务

本次新增两个 APS 任务，可按定时计划执行，也可以手动触发：

```bash
poetry run python -m src.start.commands aps generate-daily-recommendations
poetry run python -m src.start.commands aps generate-moment-recommendations
```

默认调度配置：

| 配置项 | 默认时间 | 说明 |
| --- | --- | --- |
| `daily_recommendation_generate_cron` | `0 5 * * *` | 每天生成每日推荐快照 |
| `moment_recommendation_generate_cron` | `0 4 * * *` | 每天生成推荐时刻池 |

## 体验优化

- 推荐接口统一采用“先生成快照、再分页读取”的方式，避免用户打开页面时等待实时计算。
- 每日推荐会结合最近播放、订阅演员、订阅影片、影片热度、排行榜、热评和新片信号；在缺少播放历史时，会自动使用热度、榜单、热评和新片信号完成冷启动推荐。
- 推荐时刻会优先利用用户收藏的媒体时刻进行视觉召回，不足时再用相似影片和热门影片补足。
- 推荐时刻限制同一影片最多展示 3 个时刻，减少单部影片刷屏。
- 相似影片补足推荐时，已过滤与收藏时刻同一部影片的候选，避免“相似影片推荐”把当前影片自身重复推给用户。

## 升级说明

- 新增数据库表 `daily_recommendation_item` 和 `moment_recommendation`，升级后需要执行数据库迁移或初始化流程。
- 新增配置项已写入 `config.example.toml` 与 `config.example.full.toml`；已有部署如需调整生成时间，可在实际配置文件中覆盖对应 cron。
- 推荐时刻依赖已有媒体缩略图、媒体收藏点、相似影片数据和 JoyTag 图像向量检索能力；如果这些数据较少，系统会用热门影片补足推荐池。
- Docker 构建参数 `SAKURAMEDIA_BACKEND_VERSION` 的默认值调整为 `v0.0.1`，正式镜像仍建议在构建时显式传入真实版本号。

## 兼容性说明

- 本次更新为新增接口、新增任务和新增数据表，不移除已有接口。
- 推荐读取接口都需要 Bearer Token 鉴权，与现有发现页接口保持一致。
- 推荐接口不在请求线程中触发生成；前端需要在推荐为空时展示空状态，或提示等待后台任务生成。
